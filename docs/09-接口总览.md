## 1. 鉴权语义

| 标记 | 含义 |
|---|---|
| `public` | 无需任何凭证 |
| `JWT` | `Authorization: Bearer <access_token>`（天衡所有用户都是超级用户，**无角色判断**） |
| `sk-` | `Authorization: Bearer sk-…`（平台令牌，数据库只存 sha256） |

## 2. 统一错误体

```json
{"error":{"message":"...","type":"invalid_request_error|rate_limit_error|upstream_error|security_error|api_error|permission_error","code":"...","request_id":"..."}}
```

HTTP 状态：400 参数错误 / 401 未认证 / 402 已移除（天衡无配额）/ 403 无权限 / 404 不存在 / 405 方法不允许 / 413 请求体过大 / 423 防火墙封存 / 429 仅防火墙封禁（非使用限制）/ 500 内部错误 / 502 上游不可用 / 503 存储不可用或流上限 / 504 上游超时。

## 4. 关键端点说明

### 数据面（OpenAI / Anthropic 兼容）

- `GET /v1/models` —— 返回 `data/models-real.json` 全部 460 条真实模型（`source` 字段标注来源）。
- `GET /v1/models/{id...}` —— 单模型查询；`{id...}` 为余段通配，因真实 id 含斜杠（如 `liquid/lfm-3-1.7b`）。未知 id → `404 model_not_found`，绝不合成条目。
- `POST /v1/chat/completions` —— 主入口，支持 `stream=true` 的 SSE 逐块转发；无可用上游时 `502 upstream_error`，绝不伪造模型输出。
- `POST /v1/messages` —— Anthropic Messages 兼容入口，可与 OpenAI 渠道双向协议转换。
- `POST /v1/completions|embeddings|images/generations|audio/speech|audio/transcriptions|responses` —— 按能力位转发。

### 真实数据与排行榜

- `GET /api/rankings` / `GET /api/rankings/{dimension}` / `?verify=1` —— 8 个可复核维度的完整排行榜，`source_sha256` 由真实字节实时计算。

### 全员可见监控（public）

- `GET /api/telemetry/snapshot?window=60|300|3600&bucket=10|60` —— 真实聚合快照，非法参数 400。
- `GET /api/telemetry/stream` —— SSE 每 2 秒推送，并发上限 256（超出 503）。
- `GET /api/telemetry/models` —— 按真实 model alias 的聚合排行。

### 用量（JWT）

- `GET /api/usage/series?window=&bucket=` —— 真实按桶聚合的请求数/token/花费。
- `GET /api/usage/by-model` —— 按模型聚合排行。

### 社区论坛

- `GET /api/forum/boards` / `GET /api/forum/posts?board=&q=&page=` / `GET /api/forum/posts/{id}`（public）
- `POST /api/forum/posts` / `POST /api/forum/posts/{id}/replies` / `POST /api/forum/posts/{id}/like`（JWT）
- `PUT /api/forum/posts/{id}`（作者本人编辑）/ `PUT /api/forum/posts/{id}/pin`（作者本人）
- `PUT /api/forum/posts/{id}/replies/{rid}`（回复作者本人编辑）
- `DELETE /api/forum/posts/{id}/replies/{rid}`（回复作者或帖子作者）
- `DELETE /api/forum/posts/{id}`（作者本人，级联删回复与点赞）

### 头像与资料

- `POST /api/avatar/upload`（multipart `avatar`，≤2MiB，魔数校验）/ `GET /api/avatar/me`
- `GET /api/avatar/{user_id}`（public，只返回图片字节）
- `PUT /api/profile` / `GET /api/profile` / `GET /api/profile/{user_id}`（public）

### 令牌

- `POST /api/tokens` —— 只需 `name`；所有限制字段恒被强制 0/空（天衡不设任何限制）。
- `POST /api/tokens/{id}/rotate` —— 轮换 sk-，旧令牌立即失效，新明文仅返回一次。
- `DELETE /api/tokens/{id}` —— 吊销。

### 防火墙运维

- `GET /api/firewall/status` / `GET /api/firewall/verify`（public，只读脱敏）
- `GET /api/firewall/events`（JWT）
- `POST /api/firewall/unlock|seal`（JWT + **仅本机回环**）
