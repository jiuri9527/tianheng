## 1. 架构与数据流

```
浏览器 /community、/community/[id]
   │  fetch /api/forum/*  (同源，NEXT_PUBLIC_API_BASE 可覆盖)
   ▼
Go 1.22 net/http.ServeMux（Go 1.22 method + {id} 模式）
   │  forum.Register(mux, st, cfg, auth)   ← 由 Lead 在 buildMux() 内接线
   ▼
middleware.Chain
   pub  = RequestID + CORS(cfg.CORSOrigins)
   user = RequestID + CORS + BodyLimit(cfg.BodyLimitBytes()) + Management(auth)
   │  当前用户：middleware.UserFrom(r.Context()) → *store.User（再经 st.GetUserByID 二次核验活跃）
   ▼
src/internal/forum/service.go  业务逻辑（检索/置顶优先/分页/幂等点赞/级联删除）
   ▼
src/internal/forum/storage.go  独立 JSON：<cfg.DataDir>/forum.json
   原子写 .forum.json.tmp(0600) → fsync → rename → 目录 fsync
   写锁覆盖所有写；启动校验可读；落盘失败回滚内存快照
```

**与 store 隔离**：论坛不读写 `users.json`/`channels.json` 等任何 store 表文件；`st *store.Store` 仅用于二次核验当前 JWT 对应的真实活跃用户（`GetUserByID`），以及复用 `store.NewID()` 生成带前缀 id。

**DataDir**：`cfg.DataDir/forum.json`；`cfg.DataDir == ""` 时回退 `./.llmhub-data`，与 `cmd/server/main.go` 对 `store.New` 的回退保持一致，保证运行时 JSON 同目录。

## 2. 数据模型（`models.go`）

| 实体 | 字段 | 来源 |
|---|---|---|
| `Board` | `id, slug, name, description, created_at` | **首次真实发帖提交**时按 `board`/`board_name`/`board_description` 创建；无内置版块 |
| `Post` | `id, board_id, author_id, author_name, title, content, pinned, like_count, reply_count, created_at, updated_at` | 真实 `POST /api/forum/posts`；`author_*` 来自真实 `store.User`；时间为 `time.Now().Unix()` |
| `Reply` | `id, post_id, author_id, author_name, content, created_at` | 真实 `POST /api/forum/posts/{id}/replies` |
| `Like` | `id, post_id, user_id, created_at` | 真实 `POST /api/forum/posts/{id}/like`；`(post_id,user_id)` 唯一 |

`author_name` = 真实用户邮箱 `@` 前缀（派生失败回退真实 `user_id`），**绝不编造用户名**。
`like_count` / `reply_count` 不落库可信字段：启动时由真实 Like/Reply 记录重算（`normalize()`），防止手工编辑文件造成假计数。

### 响应视图

- `BoardView`：`id, slug, name, description, post_count, created_at`
- `PostView`：`id, board_id, board_slug, author_id, author_name, title, excerpt, content?, pinned, like_count, reply_count, liked, created_at, updated_at`
- `ReplyView`：`id, post_id, author_id, author_name, content, created_at`
- `BoardList`：`{items, total}`；`PostList`：`{items, total, page, page_size, query, board}`；`PostDetail`：`{post, replies}`；`LikeResult`：`{post_id, like_count, liked}`；`ActionResult`：`{ok, id}`

所有字符串字段均为 `sanitizeText` 后的纯文本，`excerpt` 为 160 rune 摘要。

## 3. 持久化（`storage.go`）

| 要求 | 实现 |
|---|---|
| 独立 JSON | `<DataDir>/forum.json`，不进 store 的表文件列表 |
| 原子写 | `os.OpenFile(".forum.json.tmp", O_WRONLY|O_CREATE|O_TRUNC, 0600)` → `Chmod(0600)` → `Write` → `Sync()` → `Close` → `os.Rename` → 目录 `Sync()` |
| 0600 | 创建时 0600 + 显式 `Chmod(0600)`（防已存在 tmp 权限被改） |
| mutex 覆盖所有写 | `fileStore.mu sync.RWMutex`；所有 POST/PUT/DELETE 走 `write(fn)`：写锁内改内存 + 落盘，读走 `RLock`；`fn` 出错或落盘失败回滚到调用前 `cloneDatabase()` 快照 |
| 启动校验可读 | `openFileStore`：文件存在则必须可 `Open` + `ReadAll` + `json.Unmarshal`；任一失败返回 error。`Register` 无返回值，故失败时 `log.Printf` 并把 `fs=nil`，所有端点降级 `503 forum_storage_unavailable`，**绝不静默用空数据冒充成功** |
| 真实空态 | 文件不存在 / 空文件 → `newDatabase()`（四个空数组），**不预创建文件**；首次真实提交才落盘 |
| 计数一致性 | `normalize()` 保证切片非 nil（输出 `[]` 而非 `null`）并按真实记录重算 `like_count`/`reply_count` |

## 4. 真实数据 / 空态 / XSS

- **禁止种子**：`GET /api/forum/boards` 初始 `{"items":[],"total":0}`；`GET /api/forum/posts` 初始 `{"items":[],"total":0,...}`。版块不是内置常量，第一条内容出现前 `forum.json` 不存在。
- **运行时约定**：`data:[]` 与 `total:0` 是唯一无数据表达；前端 `ForumEmptyState` 明确写「论坛不预置任何演示帖子 / 版块 / 点赞数」。
- **XSS 三层**：
  1. `sanitizeText(s, maxRunes)`：去 NUL → 正则 `(?s)<[^>]*>` 剥离标签 → `strings.NewReplacer("<","‹",">","›")` → 去控制字符（保留 `\n\r\t`）→ `TrimSpace` → 按 rune 截断。
  2. `writeJSON` 用 `json.NewEncoder`（默认 `SetEscapeHTML(true)`），`< > &` 编码为 `\uXXXX`。
  3. 前端全部 `{text}` 文本节点渲染；`grep -rn dangerouslySetInnerHTML web/app/community web/components/Forum*.tsx` 只命中「禁止使用」的注释，无实际调用。
- **检索 q** 同样经 `sanitizeText` 后才回显到 `PostList.query`，不回显原始查询串。

## 6. API 契约（8 个端点）

统一错误体：`{"error":{"message","type","code","request_id"}}`（复用 `relay.WriteJSONError`）。
`request_id` 来自 `middleware.RequestID`，与响应头 `X-Request-Id` 一致。

| # | Method | Path | 链 | 鉴权 | 请求体 / 参数 | 成功响应 | 主要错误码 |
|---|---|---|---|---|---|---|---|
| 1 | GET | `/api/forum/boards` | pub | 公开 | — | `200 {items:BoardView[], total}` | `503 forum_storage_unavailable` |
| 2 | GET | `/api/forum/posts` | pub | 公开（可选 JWT 识别 liked） | `?board=&q=&page=&page_size=` | `200 PostList`（置顶优先 → 创建时间倒序 → id 倒序） | `503` |
| 3 | POST | `/api/forum/posts` | user | JWT | `{board, board_name?, board_description?, title, content}` | `201 PostView` | `400 invalid_parameter`（slug 非法/标题或内容空）、`401 missing_token`/`invalid_token`、`413 body_too_large`、`500 forum_write_failed`、`503` |
| 4 | GET | `/api/forum/posts/{id}` | pub | 公开（可选 JWT） | path `id`（`^[A-Za-z0-9_-]{1,64}$`） | `200 {post:PostView, replies:ReplyView[]}` | `400 invalid_parameter`（非法 id）、`404 not_found` |
| 5 | POST | `/api/forum/posts/{id}/replies` | user | JWT | `{content}` | `201 ReplyView` | `400`/`401`/`404`/`413`/`500`/`503` |
| 6 | POST | `/api/forum/posts/{id}/like` | user | JWT | —（幂等） | `200 {post_id, like_count, liked:true}` | `401`/`404`/`500`/`503` |
| 7 | PUT | `/api/forum/posts/{id}/pin` | user | JWT + 作者 | `{"pinned": bool}`；空 body = `true` | `200 PostView` | `400 invalid_json`/`403 forbidden`（非作者）/`404`/`500`/`503` |
| 8 | DELETE | `/api/forum/posts/{id}` | user | JWT + 作者 | — | `200 {ok:true, id}` | `403 forbidden`/`404`/`500`/`503` |

**分页**：`page` 默认 1（上限 1000000 防整数溢出），`page_size` 默认 20、上限 50；越界返回空 `items` 与真实 `total`。
**检索**：`q` 对已净化的 `title`/`content` 做大小写不敏感 `strings.Contains`；`board` 按真实版块 slug 精确过滤。
**置顶**：`pinned=true` 的帖子排在最前。
**点赞**：同一 `(post_id,user_id)` 只计一次，重复 POST 返回当前真实计数、`like_count` 不增。
**删除**：级联移除该帖的 Reply 与 Like，重开文件后计数仍为 0。
