## 1. 范围与技术栈

| 项 | 值 |
|---|---|
| 框架 | Next.js 14 App Router（`14.2.33`）+ TypeScript `5.7.3`（strict）+ Tailwind `3.4.17` |

## 6. 深浅主题切换方案

1. **零闪烁**：`app/layout.tsx` 在 `<head>` 内嵌同步脚本（与真实首页 `("class","theme","system",null,["light","dark"],…)` 同构），在 hydration 前读取 `localStorage["theme"]`（`light | dark | system`），`system` 时查 `matchMedia("(prefers-color-scheme: dark)")`，写 `<html class="light|dark">` 与 `document.documentElement.style.colorScheme`。`<html suppressHydrationWarning>`。
2. **令牌切换**：`globals.css` 的 `:root` / `.dark` 各自定义全部 RGB 三元组；`tailwind.config.ts` 用 `rgb(var(--x) / <alpha-value>)` 映射，因此 `darkMode: "class"` 下所有语义色、`bg-warning/12` 之类透明度修饰符自动随主题切换。
3. **交互切换**：`ThemeToggle` 三态按钮（`aria-pressed`），写入 localStorage 并即时更新 `<html>` class + `colorScheme`；监听系统主题变化，仅当 `theme=system` 时跟随。
4. **`viewport.themeColor`**：浅色 `#FAF9F6`、深色 `#0C0D10`，移动端浏览器 UI 同步。
5. **字体**：`<link>` 渐进加载 Plus Jakarta Sans；无网络时回退系统字体栈，不影响功能。
