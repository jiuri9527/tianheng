## 2. 统一注册函数（未修改 server.go）

```go
// src/internal/avatar/avatar.go
func Register(mux *http.ServeMux, st *store.Store, cfg *config.Config, auth *auth.Service)
```

- 签名逐字按契约，参数名 `auth` 为 `*auth.Service`（类型表达式在包作用域解析到 import，函数体内即该服务实例）。
- **未改动** `src/internal/api/server.go`、`src/cmd/server/main.go`、任何其它包文件。
- 包内用 `middleware.Chain` 包装，pub / user 与论坛约定一致：

```go
func (s *Service) pub(h http.HandlerFunc) http.Handler {
    return middleware.Chain(h, middleware.RequestID, middleware.CORS(s.cfg.CORSOrigins))
}
func (s *Service) user(h http.HandlerFunc) http.Handler {
    return middleware.Chain(h,
        middleware.RequestID,
        middleware.CORS(s.cfg.CORSOrigins),
        middleware.BodyLimit(avatarBodyLimit),   // 2MiB + 64KiB multipart 余量
        middleware.Management(s.auth),           // JWT，注入 KeyUser
    )
}
```

- 当前用户一律用 `middleware.UserFrom(r.Context())` 取得；**不接受任何请求体/查询参数里的 user_id**。
- 装配层只需在自己的 `buildMux()` 里追加一行 `avatar.Register(mux, st, cfg, authSvc)`（见第 8 节集成说明）。

## 3. 端点契约

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/avatar/upload` | user | multipart/form-data 字段 `avatar`；返回 `{ok, avatar, profile, request_id}` |
| GET | `/api/avatar/me` | user | 本人头像元数据 + 资料（`Cache-Control: private, no-store`） |
| GET | `/api/avatar/{user_id}` | public | **只返回图片字节**；默认 128×128 缩略图，`?original=1` 返回原图 |
| PUT | `/api/profile` | user | `{nickname, bio}`，转义后落盘，返回 `{ok, profile, limits}` |
| GET | `/api/profile` | user | 读取本人资料，无数据 `has_data:false`（真实空态） |
| GET | `/api/profile/{user_id}` | public | 公开资料视图，不含邮箱/角色/余额 |

统一错误体沿用 `relay.WriteJSONError` → `{"error":{"message","type","code","request_id"}}`；公开图片端点成功时不返回任何 JSON，并设置
`X-Content-Type-Options: nosniff`、`Content-Security-Policy: default-src 'none'; sandbox`、`Content-Disposition: inline`。

`GET /api/avatar/me`（字面量段）与 `GET /api/avatar/{user_id}`（通配符段）在 Go 1.22 ServeMux 下按「更具体者优先」注册，无冲突。

## 4. 校验链（逐条落实，无简化）

1. **multipart 字段**：`r.MultipartReader()` 流式读取，只取 `FormName()=="avatar"` 的 part；缺字段返回 400 `invalid_upload`。
2. **大小 ≤ 2MiB**：`io.LimitReader(part, maxAvatarBytes+1)` 多读 1 字节判定，超限返回 413 `avatar_too_large`；`middleware.BodyLimit` 同时限制整个请求体。
3. **真实文件魔数**（`sniff`，只依据字节，不看文件名/CT）：
   - PNG `89 50 4E 47 0D 0A 1A 0A` → `.png` / `image/png`
   - JPEG `FF D8 FF` → `.jpg` / `image/jpeg`
   - WebP `RIFF` + 偏移 8 的 `WEBP` → `.webp` / `image/webp`
   - GIF `47 49 46 38`（`GIF8`）+ 版本 `7a|9a` → `.gif` / `image/gif`
4. **Content-Type**：必须在 `image/png|jpeg|webp|gif` 内，且必须与魔数判定一致（去 `;charset` 后小写比较）。错配返回 400 `invalid_avatar`。
5. **绝不采信用户文件名**：`part.FileName()` 被刻意忽略，不进入路径、响应或日志；落盘名来自服务端认证用户 id + 白名单扩展名；同时生成 `crypto/rand` 16 字节随机 `avatar_id` 作为版本号/缓存串。前端上传时亦用中性名 `avatar` 提交，测试用 `../../evil<script>.png` 验证不会落盘。
6. **路径穿越/XSS 防护**：`safeUserID = ^[A-Za-z0-9_-]{1,128}$` 校验 `user_id`；扩展名只来自 `allowedExts` 白名单；`avatarPath` 二次确认 `filepath.Dir(clean) == avatarsDir`。
7. **权限**：`DataDir` 与 `avatars/` 均 `0700`，所有文件 `0600`；写入走 `os.CreateTemp` 同目录临时文件 → `Chmod(0600)` → `Write` → `Sync` → `Close` → `os.Rename` → `Chmod(0600)` → 目录 `Sync`，无半截文件。
8. **真实解码校验**：PNG/JPEG/GIF 用标准库 `image/png|jpeg|gif` 注册解码器，`image.DecodeConfig` 先校验内部格式与像素总量 ≤ 25MP（防压缩炸弹），再 `image.Decode` 真实解码；失败 400 `decode_failed`。
9. **128×128 缩略图**：`resizeBox` 中心正方形裁剪 + 盒式均值降采样，纯标准库（无 `golang.org/x/image/draw`），编码为 PNG 落 `&lt;userid&gt;.thumb.png`。
10. **WebP 特例**：标准库无 WebP 解码器 → 仅按魔数校验后**原样保存**，元数据标记 `decoded=false`、`has_thumbnail=false`，公开端点按 `image/webp` 返回原始字节。
11. **昵称/简介**：`utf8.ValidString` → 去首尾空白 → 清控制字符（保留 `\n`/`\t`）→ 按 rune 限长（昵称 32 / 简介 280）→ `html.EscapeString` 转义后落盘。前端 `decodeEntities` 仅用于回填编辑框，永不执行/注入 HTML。
12. **资料落盘**：`cfg.DataDir/profiles.json`，`sync.RWMutex` 保护，`Update` 先写盘成功再提交内存（避免并发覆盖与半写）；文件不存在时为空表，**禁止预置任何假资料**。
13. **公开资料脱敏**：`publicProfileView` 只含 `user_id / nickname / bio / has_avatar / avatar_url`。

## 5. 数据模型

```json
{
  "profiles": {
    "usr_xxx": {
      "user_id": "usr_xxx",
      "nickname": "已转义文本",
      "bio": "已转义文本",
      "avatar_id": "<32 hex 随机>",
      "avatar_ext": ".png",
      "avatar_content_type": "image/png",
      "avatar_bytes": 12345,
      "avatar_decoded": true,
      "has_thumbnail": true,
      "updated_at": 1730000000
    }
  }
}
```

落盘文件：
- `cfg.DataDir/avatars/&lt;userid&gt;.&lt;ext&gt;`（0600）
- `cfg.DataDir/avatars/&lt;userid&gt;.thumb.png`（0600，仅 PNG/JPEG/GIF）
- `cfg.DataDir/profiles.json`（0600）

`cfg.DataDir` 为空时与 `src/cmd/server/main.go` 一致回落 `./.llmhub-data`。
